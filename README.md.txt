# Sales Management System

## Project Overview
A SQL-based Sales Management System designed to manage customers,
products, and orders and perform basic sales analysis.

## Technologies Used
- MySQL
- SQL

## Database Tables
- Customers
- Products
- Orders

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT
- SELECT
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions

## Project Analysis
The project analyzes customer orders, product-wise sales,
total sales, and customer spending.

## Project Files
- `Sales_Management.sql` – Complete SQL script containing database creation,
  table creation, sample data, and analysis queries.
